# Blockchain Authentication System

A decentralized identity verification and authentication system built using:

- Ethereum Smart Contracts (Solidity)
- Truffle Framework
- Web3.js
- React.js

## Setup

1. Clone the repository

```bash
git clone https://github.com/sanxalp/blockchain-based-auth.git
cd blockchainauthentication
```

2. Install dependencies

```bash
npm install
cd client
npm install
```

3. Start local blockchain

use Ganache and quickstart then go to contracts and add your truffle-config.js there

4. Deploy contracts

```bash
truffle migrate
```

5. Start the client

```bash
cd client
npm start
```

## Technology Stack

- Solidity ^0.8.6
- Truffle Framework
- Web3.js 1.2.2
- React.js
- MetaMask (Web3 Provider)
